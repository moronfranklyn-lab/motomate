# MotoMate 黄金评测 V0.1

## 目标

本评测集把产品规则转换为50条离线、确定性、可重复执行的发布契约。它验证用户需求澄清、推荐候选、预算边界、候选覆盖、价格状态、二手风险边界、库外证据与费用降级，不调用实时搜索或模型。

## 基线

- 候选池：`mvp_eligible_pool_v0.1`，17配置
- 语义层：`mvp_semantic_v0.1`
- 正式推荐批准数：0
- 运行命令：`node scripts/run-golden-evals.mjs`

## 类别

| 类别 | 数量 | 核心风险 |
| --- | ---: | --- |
| conversation | 6 | 信息不足时漏问、多问或提前推荐 |
| intent | 3 | 价格、二手、维修意图路由错误 |
| recommendation | 19 | 候选越界、排序回归、自动放宽条件 |
| coverage | 3 | 候选不足却不触发扩展搜索 |
| budget | 3 | 裸车与落地预算混用 |
| price | 4 | 过期、缺失或冲突价格被当作确定价格 |
| used | 4 | 根据文字臆断事故、泡水或调表 |
| external | 6 | 搜索线索未经双源核验或核验后超预算 |
| cost | 2 | 费用越线后仍调用付费能力 |

## 变更纪律

知识库、排序规则或产品政策变化导致黄金用例失败时，先判断是缺陷还是预期行为。只有产品规则确实变化且相关文档、测试理由和版本同时更新时，才修改黄金答案；不得为了恢复绿色结果直接改期望值。

50/50通过只代表当前离线产品契约成立，不代表车型事实已获正式推荐批准，也不代替真实用户可用性测试、联网质量监控或公网安全验收。
