## 2. 来源可访问性与冲突

- 无极两个官方详情页可访问，完整参数弹窗可核验排量、座高、质量、功率和油箱。官网参数摘要组件曾出现错位值，采用完整参数弹窗并记录异常；官方展示价与摩托范数值一致，无价格数值冲突。
- 五羊本田当前产品目录和 PCX 详情页可访问，官方建议零售价与摩托范一致，无价格冲突。官网“Honda可选扭矩控制系统”不能直接等同于“选装”或“标配可关闭”。
- 雅马哈中国目录及两个 NMAX 独立详情页可访问，官方建议零售价与摩托范一致，无价格冲突。Tech Max 的颜色介绍与参数表存在官网内部不一致，非本轮目标字段。
- 所有抓取与核验时间均记录在单配置证据输入和核验 JSON 中；无法闭环字段保持待人工复核，不以模型记忆补全。

- 最终用于批次验收的 5 条配置草稿：HTTP 和 JSON 解析 5/5 通过，URL 白名单 5/5 通过。
- 配置绑定通过 3/5，批次路由通过率 60%；SR250GT 两配置因 `trim_name` 为空失败。

- 连续解析/根结构/Schema 失败次数为 0，未触发“三连结构失败”熔断。
- `batch_route_approved=false`。当前路由可继续处理 PCX/NMAX 风格的单配置输入，但 SR250GT 需要修正抽取 Schema 或后处理规则后单独复验，不能宣布本批次整体可批量化。

## 5. 数据分层

- `extraction_draft`：7 个智谱原始草稿，含 2 个首次失败、2 个重试失败和 3 个通过。
- 已核验字段：只写入 `knowledge_base_outputs/verified/` 下的人工复核 JSON，并按字段记录状态。
- 待人工复核字段：年款、价格口径、功率、ABS/TCS 等均在各车型 blocker 中列出。
- 可进入结构化推荐的数据：本轮为 0；指定字段通过不等于完成完整准入 checklist。
- 仅进入向量证据库的资料：本轮未执行向量化；后续只允许用于证据召回和解释，不参与准入、预算筛选或排序。

## 6. 工程边界

- API Key 仅由本机 `.env` 读取，未读取、打印或写入产物。
- 失败最多重试 2 次；本轮仅使用 1 次重试。
- 逐批记录 usage、HTTP、解析状态、输出文件；三连结构失败触发熔断。
- Ethan 反馈账户页面显示约 1000 万可用额度，本轮未独立核对适用范围或抵扣明细，不作为平台已确认事实。
