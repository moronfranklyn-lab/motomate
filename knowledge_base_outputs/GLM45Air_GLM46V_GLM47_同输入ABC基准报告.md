# GLM-4.5-Air / GLM-4.6V / GLM-4.7 同输入 A/B/C 基准

验收日期：2026-08-28（Asia/Shanghai）  
结论状态：路由建议；未永久修改默认模型。

## 1. 公平性条件

- 三个样本：SR250GT Play版、SR250GT Pro版、UHR150 扶手版。
- 三模型使用完全相同的公开文本输入、system/user prompt、JSON Schema、`temperature=0.1`、`max_tokens=1000`、关闭思考和单配置 `model` 根对象。
- `glm-4.6v` 本轮仅接受纯文本，没有使用图片或视觉能力，不给予视觉能力加分。
- 本地统一校验 14 个字段、年款/配置/价格/车重绑定、URL 白名单和非空字段来源。
- 模型输出全部是 `extraction_draft`，没有改写已核验知识库。

## 2. 首次调用结果

| 模型 | HTTP 200 | JSON | 14/14 | 绑定通过 | 白名单 | 无来源补全 | Token | 平均延迟 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| glm-4.5-air | 3/3 | 3/3 | 2/3 | 2/3 | 3/3 | 0 | 3631 | 25.61s |
| glm-4.6v | 3/3 | 3/3 | 3/3 | 3/3 | 3/3 | 0 | 3723 | 22.81s |
| glm-4.7 | 3/3 | 3/3 | 3/3 | 3/3 | 3/3 | 0 | 3367 | 11.81s |

`无来源补全=0` 表示所有模型返回的来源 URL 均在对应输入白名单内，且所有非空目标字段均提供来源。它不等于字段事实已经人工核验。

## 3. 样本级结果

| 模型 | SR Play | SR Pro | UHR 扶手版 |
|---|---|---|---|
| glm-4.5-air | 通过，14/14 | 失败，13/14，`trim_name=null` | 通过，14/14 |
| glm-4.6v | 通过，14/14 | 通过，14/14 | 通过，14/14 |
| glm-4.7 | 通过，14/14 | 通过，14/14 | 通过，14/14 |

三个模型全部返回 HTTP 200 且 JSON 可解析，没有 API 参数不兼容。`glm-4.6v` 返回的 reasoning token 为 0，符合关闭思考的请求。

## 4. 失败重试与稳定性

`glm-4.5-air` 的 SR250GT Pro 首次失败后进行一次重试：HTTP 200、JSON 可解析、1280 tokens、14.61 秒，但仍为 13/14，`trim_name=null`，配置绑定继续失败。结合此前同输入多次相同失败，可以确认该模型在 SR 配置名拆分上存在重复性问题，而不是一次偶发网络错误。

`glm-4.6v` 和 `glm-4.7` 三个样本均首次通过，因此未触发重试。每模型每样本只有一次成功调用，当前只能确认“小样本首轮稳定”，不能外推为长期稳定率；后续扩大前应继续记录滚动通过率。

## 5. Token 与延迟

- `glm-4.7` 首次三调用合计 3367 tokens，比 `glm-4.6v` 少 356（约 9.6%），比 `glm-4.5-air` 少 264（约 7.3%）。
- `glm-4.7` 平均延迟 11.81 秒，比 `glm-4.6v` 快约 48%，比 `glm-4.5-air` 快约 54%。
- `glm-4.5-air` 首次合计 3631 tokens；加失败重试后实际为 4911 tokens，且仍未修复 SR Pro。
- 延迟为客户端单次端到端观测，受当时网络和平台负载影响；小样本不应作为服务 SLA。

## 6. 路由建议

**默认文本抽取：`glm-4.7`。** 本轮结构与绑定正确率和 `glm-4.6v` 同为 100%，但 Token 更少、延迟明显更低。该结论只适用于当前公开文本、固定 Schema、单配置抽取任务；暂不修改 `.env` 或永久默认值。

**图片/截图抽取：暂定 `glm-4.6v`。** 这是基于模型接口定位的候选路由，不是本轮视觉效果结论。本轮没有图片输入，正式启用前必须另做相同图片集的字段准确率、OCR、隐私和成本基准。

**文本失败降级：** `glm-4.7` → `glm-4.6v` → `glm-4.5-air` → 人工复核。任一结果仍须通过 Schema、白名单、配置绑定和事实核验；失败模型不能用另一个模型的输出自动“投票升级”。

**图片失败降级：** `glm-4.6v` → 本地 OCR/脱敏后把公开文本交给 `glm-4.7` → 人工复核。未完成隐私链路前，不向外部模型发送真实用户图片。

## 7. 额度与安全边界

- Ethan 反馈账户页面显示 `glm-4.7` 约有 500 万 Token，尚未独立核对适用范围及抵扣明细，不写成平台已核验事实。
- 保留单请求上限、usage 日志、有限重试和连续失败熔断，不因额度较高启用无限循环。
- API Key 只由本机 `.env` 加载，未读取、打印或记录。
